# Правила репозитория notes

Это инварианты, а не пожелания. Ассистент сверяет их с файлами и пишет отчёт.

1. Каждый публичный символ модуля `src/notes/api.py` — функция или класс без ведущего подчёркивания — должен быть назван в разделе «API» файла `README.md`. Если в коде появилась функция, а в README её нет, правило нарушено.
2. У каждой публичной функции в `src/notes/api.py` должен быть docstring. Пустая строка документации не считается.
3. Модули кроме `src/notes/cli.py` не импортируют `notes.cli` и не импортируют из него имена. CLI — край дерева, не зависимость библиотеки.

Сигнатуры в README должны совпадать с кодом: имена аргументов — как в определении функции, не синонимы вроде `text` вместо `body`.
