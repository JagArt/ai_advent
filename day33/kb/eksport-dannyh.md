# Экспорт данных

Проект экспортируется целиком — задачи, комментарии, вложения — из меню проекта «⋯» → «Экспорт».

## Форматы

CSV доступен на всех тарифах: одна строка — одна задача, комментарии в отдельном столбце через разделитель. XLSX — на Pro и Team, с листами по статусам. JSON — на Pro и Team, полная структура с идентификаторами, подходит для переноса в другой инструмент. Вложения выгружаются ZIP-архивом отдельной кнопкой.

## Экспорт не скачивается

Экспорт большого проекта готовится в фоне: кнопка меняется на «Готовится…», и ссылка приходит на почту в течение 10 минут. Ссылка действует 24 часа. Если письма нет — проверьте «Спам»; повторный запуск экспорта раньше чем через 10 минут игнорируется.

## Кодировка CSV

Файл в UTF-8 с BOM, Excel открывает его корректно двойным щелчком. Если кириллица отображается знаками вопроса, откройте файл через «Данные» → «Из текста/CSV» и выберите UTF-8.

## Экспорт всего аккаунта

Выгрузка всех проектов одним архивом — «Настройки» → «Данные» → «Запросить архив». Готовится до суток, ссылка приходит на почту. Это же используется для переноса данных и при удалении аккаунта.
