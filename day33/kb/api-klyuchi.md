# API: ключи и доступ

Публичный API доступен на тарифах Pro и Team. Документация — на `api.planerka.app/docs`, базовый адрес `https://api.planerka.app/v1`.

## Создать ключ

«Настройки» → «API» → «Создать ключ». Ключ показывается один раз, скопируйте его сразу. У ключа есть имя и права: только чтение или чтение и запись. Ключей может быть до 10 на аккаунт.

## Авторизация запросов

Ключ передаётся в заголовке `Authorization: Bearer <ключ>`. Ответ `401 Unauthorized` означает, что ключ не передан, отозван или относится к аккаунту, у которого закончился Pro — при понижении до Free все ключи аккаунта перестают работать, но не удаляются и оживают при повышении тарифа.

## Ключи команды

На тарифе Team администратор создаёт ключи команды с доступом ко всем проектам. Ключи отдельных участников видят только проекты, к которым у участника есть доступ.

## Отозвать ключ

«Настройки» → «API» → корзина рядом с ключом. Отзыв мгновенный. При подозрении на утечку отзовите ключ и создайте новый — восстановить отозванный нельзя.
