## Установка

Общее виртуальное окружение в корне, зависимости — под конкретный день:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r day2/requirements.txt
```

Зависимости `day2`–`day7` и `day11`–`day15` совпадают, в `day8`–`day10` к ним добавляется `tiktoken` — им считаются токены до отправки запроса, в `day16`–`day17` — `mcp`, SDK протокола.

## Настройка

Скопируйте `.env.example` в `.env` и укажите ключи:

```
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
DEEPSEEK_MODEL=deepseek-v4-flash
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxx
```

`.env` лежит в корне и подхватывается из папок day1–day17. `DEEPSEEK_MODEL` необязателен и читается в `day2`–`day4` и `day6`–`day17`, по умолчанию используется `deepseek-v4-flash`; в `day1` модель задана в коде, в `day5` — список моделей.

`OPENROUTER_API_KEY` нужен только в `day5`: слабая модель берётся из OpenRouter, потому что DeepSeek API отдаёт всего два уровня — `deepseek-v4-flash` и `deepseek-v4-pro`.

## Запуск

Команды рассчитаны на запуск из корня проекта, с активированным `.venv`.

`day1` — скрипт в терминале:

```bash
python day1/main.py
```

`day2`–`day17` — веб-интерфейс на FastAPI, команда одна и та же, меняется только папка:

```bash
uvicorn main:app --reload --app-dir day15
```

Интерфейс доступен на http://127.0.0.1:8000, а в `day10` рядом с чатом есть http://127.0.0.1:8000/scenarios — замеры стратегий кнопкой, с готовым markdown для README.

Замеры `day9` и `day11`–`day15` запускаются скриптом, а не из браузера, — вывод сразу в markdown:

```bash
python day15/scenarios.py
```

В `day16` и `day17` из терминала запускается сам MCP-клиент — соединение и список инструментов, без веба и без ключей. В `day17` клиент ещё вызывает `git_log` и печатает результат:

```bash
python day17/client.py
```
