# AI Advent

Итерации проекта по дням, каждая в своей папке. Подробности итерации — в README её папки.

| Папка | Итерация |
| --- | --- |
| [day1/](day1/README.md) | CLI: запрос из терминала, потоковый вывод в stdout |
| [day2/](day2/README.md) | Веб-интерфейс: сравнение свободного ответа и ответа по ограничениям из JSON |
| [day3/](day3/README.md) | Веб-интерфейс: одна задача, один запрос — способы рассуждения из чекбоксов |
| [day4/](day4/README.md) | Веб-интерфейс: один запрос, температура задаётся слайдером |
| [day5/](day5/README.md) | Веб-интерфейс: один запрос уходит в три модели разной силы, замеры времени, токенов и стоимости |
| [day6/](day6/README.md) | Веб-чат: агент с памятью диалога — отдельная сущность, инкапсулирующая промпт, историю и вызов LLM |
| [day7/](day7/README.md) | Веб-чат: история диалогов в SQLite — переписка переживает перезапуск процесса, диалогов может быть несколько |
| [day8/](day8/README.md) | Веб-чат: подсчёт токенов запроса, истории и ответа, бюджет контекста в токенах, стоимость по ходам |
| [day9/](day9/README.md) | Веб-чат: сжатие истории — последние сообщения дословно, остальное конспектом, который агент пишет себе сам |
| [day10/](day10/README.md) | Веб-чат: три стратегии управления контекстом — скользящее окно, картотека фактов, ветки диалога — и переключатель между ними |

## Установка

Общее виртуальное окружение в корне, зависимости — под конкретный день:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r day2/requirements.txt
```

Зависимости `day2`–`day7` совпадают, в `day8`–`day10` к ним добавляется `tiktoken` — им считаются токены до отправки запроса.

## Настройка

Скопируйте `.env.example` в `.env` и укажите ключи:

```
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
DEEPSEEK_MODEL=deepseek-v4-flash
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxx
```

`.env` лежит в корне и подхватывается из папок day1–day10. `DEEPSEEK_MODEL` необязателен и читается в `day2`–`day4` и `day6`–`day10`, по умолчанию используется `deepseek-v4-flash`; в `day1` модель задана в коде, в `day5` — список моделей.

`OPENROUTER_API_KEY` нужен только в `day5`: слабая модель берётся из OpenRouter, потому что DeepSeek API отдаёт всего два уровня — `deepseek-v4-flash` и `deepseek-v4-pro`.

## Запуск

Команды рассчитаны на запуск из корня проекта, с активированным `.venv`.

`day1` — скрипт в терминале:

```bash
python day1/main.py
```

`day2`–`day10` — веб-интерфейс на FastAPI, команда одна и та же, меняется только папка:

```bash
uvicorn main:app --reload --app-dir day10
```

Интерфейс доступен на http://127.0.0.1:8000, а в `day10` рядом с чатом есть http://127.0.0.1:8000/scenarios — замеры стратегий кнопкой, с готовым markdown для README.
